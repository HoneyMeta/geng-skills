# 数据造假信号 · 判读参考

`geng_check.py data` 会输出以下类型的候选信号。每条都是**线索而非结论**，需结合上下文判断是否有正当解释。

---

## 1. `terminal_digit_uniformity` — 末位数字分布异常

**原理**：真实测量数据的最后一位有效数字通常近似均匀分布（0–9 各约 10%）。
人为编造或"凑"出来的数据，末位常出现强烈偏斜。

**耿同学经典案例**：某 Nature 子刊里 2400 个数据末尾**全是 5**。

**统计**：对末位数字做卡方拟合优度检验（期望均匀），输出 `chi2 / pValue / distribution / dominantDigit / dominantShare`。

**严重度**：p<1e-6 → high；p<1e-3 → medium；p<0.01 → low。

**正当原因（需排除）**：
- 仪器读数到固定刻度（如只能读到 .0 / .5）。
- 单位换算后末位被系统性改变。
- 数据本身是整数计数、百分比、评分量表（末位天然不均匀）。
- 大量四舍五入到同一精度。

---

## 2. `benford_first_digit` — 首位数字偏离 Benford 定律

**原理**：横跨多个数量级的自然数据，其首位数字（1–9）通常服从 Benford 分布
（P(d)=log10(1+1/d)，即 1 出现约 30%，9 约 4.6%）。显著偏离值得关注。

**统计**：仅当数据跨度 ≥2 个数量级且 n≥50 时才检验；输出 `chi2 / pValue / orderSpan / observed`。

**严重度**：p<1e-4 → medium；p<0.01 → low。

**正当原因（需排除）**：
- 有界量、受物理约束的量（如 pH、百分比、温度区间）本就不服从 Benford。
- 人为设定的浓度梯度、剂量序列。
- 样本量偏小导致的随机偏离。

> Benford 偏离**不能单独**作为造假证据，仅作辅助线索。

---

## 3. `arithmetic_progression` — 完美等差数列

**原理**：实验/统计数据极少天然呈现完美线性。某一列/行若是严丝合缝的等差数列，可能是人为填充。

**统计**：序列长度≥5，相邻差值几乎恒定（相对偏差<1e-6）时触发；输出 `commonDifference / sample`。

**严重度**：medium（需解释）。

**正当原因（需排除）**：
- 坐标轴刻度、时间点、序号、设定的浓度/剂量梯度、标准曲线的 x 值。
- 这些"自变量"本就该是等差的，**不是**造假。重点看是否出现在**因变量/测量结果**列。

---

## 4. `duplicate_data_block` — 重复数据块

**原理**：同一段数值（≥4 个、且非全相同）在多处出现，是复制粘贴的强信号。
跨样本、跨实验条件出现相同数据块，"不小心"难以解释。

**统计**：输出 `block / occurrences / where`。

**严重度**：high。

**正当原因（需排除）**：
- 对照组在多张表里被合理复用（应核对是否标注清楚）。
- 同一数据在汇总表与明细表中重复呈现（正常）。

---

## 5. `duplicate_row` — 完全重复的数据行

**原理**：一整行（≥3 个数值且全部一致）重复出现，可能是行被复制。

**严重度**：high。

**正当原因（需排除）**：模板行、表头残留、合理的重复测量记录。

---

## 6. GRIM（按需，`geng_check.py grim`）

**原理**：报告的均值 `mean`（小数位 `decimals`）在样本量 `n` 下，必须能由某个整数总和还原。
否则均值在数学上不可能——可能是笔误或编造。

**用法**：当正文出现 "mean = X (n = N)" 且数据为整数量表（如李克特量表、计数）时，对可疑值检验。

**输出**：`consistent`（是否自洽）、`impliedSum`、说明。

**局限**：仅适用于小样本、离散整数数据；对连续测量、大样本不适用。

---

## 7. `decimal_place_inconsistency` — 小数位异常不一致（自动，弱信号）

**原理**：同一测量列的精度通常一致（同一台仪器、同一记录规范）。若一列里混杂多种小数精度
且没有主导精度，可能是从不同来源拼接或复制粘贴而来。

**统计**：仅对**列**检查；列以小数为主（≥60% 有小数）、精度种类≥3、且主导精度占比<70% 时触发。
输出 `distinctPrecisions / dominantDecimals / dominantShare / profile`。

**严重度**：low（弱信号）。

**正当原因（非常常见，需排除）**：
- **去尾零**：1.50 被写成 1.5、2.00 写成 2，导致小数位天然参差——这是最常见的误报来源。
- 整数与小数混排（如恰好等于整数的测量值）。
- 不同量级的量同列（一般不应同列，但偶有）。

> 这是提示性信号，**几乎总有正当解释**。仅在它与其他 high 信号叠加、或精度跳变明显异常时才值得追究。

---

## 8. SPRITE-lite（按需，`geng_check.py sprite`）

**原理**：对有界数据（取值在 [min, max]，如李克特量表 1–7、百分比 0–100），给定均值时
标准差存在**理论上界**：总体方差 ≤ (mean−min)(max−mean)，样本 SD 再乘 √(n/(n−1))。
若报告的 SD 超过该上界，则在该区间与均值下**数学上不可能**——SD 太大装不进这个区间。

**耿同学式硬伤**：和 GRIM 一样属于"失误无法解释"的数学不可能，是强信号。

**用法**：当正文给出 "mean ± SD, n=…" 且数据有明确取值范围时，对可疑值检验：
```
python scripts/geng_check.py sprite --mean 2.0 --sd 3.0 --n 20 --min 1 --max 7
# 默认按样本SD(除以 n-1)；如报告的是总体SD(除以 n)，加 --population
```

**输出**：`consistent`、`maxPossibleSd`（理论上界）、说明。

**严重度**：不一致 → high。

**局限**：
- 必须知道取值上下界（量表、百分比等才适用；无界的连续测量不适用）。
- 只检上界（SD 过大）；SD 过小、或离散数据的精细可行性（完整 SPRITE 的重构）不在本 lite 版范围。
- `consistent=true` 只说明 SD 在数学上可能，**不代表数据真实**。

---

## 判读总原则

1. **先问"有没有正当解释"**：自变量列等差是正常的，对照组复用是正常的，刻度限制导致末位偏斜是正常的。
2. **多信号叠加才可信**：单一弱信号（如 Benford 轻微偏离）不足为据；多个 high 信号集中在同一张表才值得高度警惕。
3. **耿同学准则**：找那些"失误无法解释"的硬伤——完整重复的数据块、2400 个末位全 5、GRIM 数学不可能。
4. 最终在 `verdicts.json` 里给每条 finding 标注 `需复核 / 确认问题 / 可解释` 并写清依据。
